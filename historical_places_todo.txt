===========================================================

1. FILTER PHÂN CẤP (cha → con)
   - Hiện tại: filter "Hà Nội" không bắt được "Hoàn Kiếm" (con của Hà Nội)
   - Cần: bảng locations tự tham chiếu (parentId)
   - Ví dụ:
       Việt Nam (COUNTRY)
         └── Hà Nội (PROVINCE)
               └── Hoàn Kiếm (CITY)

2. CHUẨN HÓA DỮ LIỆU (tránh typo)
   - Hiện tại: "Hà Nội" vs "Hà nội" vs "Ha Noi" → không khớp khi filter
   - Cần: bảng historical_places làm lookup table chuẩn
   - Admin chọn từ dropdown thay vì tự gõ

3. AUTOCOMPLETE / SUGGEST KHI TÌM KIẾM
   - Hiện tại: ILIKE '%Hà Nội%' → chậm nếu data lớn, không suggest
   - Cần: pg_trgm extension + GIN index cho trigram search
   - Hoặc: Elasticsearch nếu scale lớn

4. THỐNG KÊ THEO ĐỊA LÝ
   - "Bao nhiêu bài học về Hà Nội?"

   - Cần: bảng chuẩn hóa để GROUP BY chính xác

===========================================================
SCHEMA ĐỀ XUẤT KHI LÀM (tương lai):
===========================================================

model historicalPlace {
  id          String       @id @default(uuid())
  name        String       // "Sông Bạch Đằng", "Hoàng Thành Thăng Long"
  type        LocationType // COUNTRY / PROVINCE / CITY / REGION
  parentId    String?      // Self-ref: Hà Nội → parentId = VietNam.id
  country     String       @default("Việt Nam")
  code        String?      // ISO hoặc tự đặt: "HN", "QN"
  description String?      @db.Text

  parent   historicalPlace?  @relation("PlaceHierarchy", fields: [parentId], references: [id])
  children historicalPlace[] @relation("PlaceHierarchy")

  // Ánh xạ ngược
  periods historicalEvent[]
  topics  topic[]

  @@index([parentId])
  @@index([type])
  @@index([country])
}

enum LocationType {
  CONTINENT // Châu Á, Châu Âu
  COUNTRY   // Việt Nam, Pháp, Trung Quốc
  PROVINCE  // Hà Nội, Quảng Ninh, Thừa Thiên Huế
  CITY      // Hoàn Kiếm, Điện Biên
  REGION    // Champa, Phù Nam, Đại Việt (vùng lịch sử không còn tồn tại)
}
